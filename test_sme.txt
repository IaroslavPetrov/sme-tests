СОВР. МЕТОДЫ ЛАБ. ИСЛЕД. В ОТД. СУД.МЕД. ЭКСПЕРТИЗЫ
#ПРИ ПРОВЕДЕНИИ СУДЕБНО-МЕДИЦИНСКОЙ ЭКСПЕРТИЗЫ СОСТАВЛЯЕТСЯ ДОКУМЕНТ:
- ПРОТОКОЛ СУДЕБНО-МЕДИЦИНСКОГО ИССЛЕДОВАНИЯ;
- АКТ СУДЕБНО-МЕДИЦИНСКОЙ ЭКСПЕРТИЗЫ;
+ ЗАКЛЮЧЕНИЕ ЭКСПЕРТА;
- АКТ СУДЕБНО-МЕДИЦИНСКОГО ИССЛЕДОВАНИЯ;
- ПРОТОКОЛ СУДЕБНО-МЕДИЦИНСКОЙ ЭКСПЕРТИЗЫ.
#ЗАКЛЮЧЕНИЕ ЭКСПЕРТА СОСТОИТ ИЗ СЛЕДУЮЩИХ РАЗДЕЛОВ, КРОМЕ:
- ВВОДНОЙ ЧАСТИ;
- ОБСТОЯТЕЛЬСТВ ДЕЛА;
- ИССЛЕДОВАТЕЛЬСКОЙ ЧАСТИ;
- ВЫВОДОВ;
+ ЭПИКРИЗА.
#ИССЛЕДОВАТЕЛЬСКУЮ ЧАСТЬ ЗАКЛЮЧЕНИЯ ЭКСПЕРТА ПОДПИСЫВАЮТ:
- ЛИЦО, НАЗНАЧИВШЕЕ ЭКСПЕРТИЗУ;
+ ЭКСПЕРТ, ПРОИЗВОДИВШИЙ ЭКСПЕРТИЗУ;
- ПОНЯТЫЕ;
- СВИДЕТЕЛИ, ПРОХОДЯЩИЕ ПО ДАННОМУ ДЕЛУ;
#В СООТВЕТСТВИИ С УПК РФ, ПРОВЕДЕНИЕ ЭКСПЕРТИЗЫ ОБЯЗАТЕЛЬНО:
+ ДЛЯ УСТАНОВЛЕНИЯ ПРИЧИН СМЕРТИ;
- ДЛЯ ОПРЕДЕЛЕНИЯ ПСИХИЧЕСКОГО СОСТОЯНИЯ ОБВИНЯЕМОГО;
- ДЛЯ ОПРЕДЕЛЕНИЯ ПОЛОВОЙ ЗРЕЛОСТИ.
#РАЗРЕШЕНИЕ КАКИХ ВОПРОСОВ ЯВЛЯЕТСЯ ОБЯЗАТЕЛЬНЫМ ПРИ СУДЕБНО-МЕДИЦИНСКОЙ ЭКСПЕРТИЗЕ ТРУПОВ?
+ УСТАНОВЛЕНИЕ ПРИЧИН СМЕРТИ;
+ НАЛИЧИЕ ТЕЛЕСНЫХ ПОВРЕЖДЕНИЙ;
+ ДАВНОСТЬ ОБРАЗОВАНИЯ ТЕЛЕСНЫХ ПОВРЕЖДЕНИЙ;
+ МЕХАНИЗМ ОБРАЗОВАНИЯ ТЕЛЕСНЫХ ПОВРЕЖДЕНИЙ;
#ДОКАЗАТЕЛЬСТВАМИ МОГУТ СЛУЖИТЬ:
+ ЗАКЛЮЧЕНИЯ ЭКСПЕРТОВ;
+ ПОКАЗАНИЯ СВИДЕТЕЛЕЙ;
+ ПРОТОКОЛЫ СЛЕДСТВЕННЫХ ДЕЙСТВИЙ;
+ ПОКАЗАНИЯ ОБВИНЯЕМОГО.
#ДОКАЗАТЕЛЬСТВА МОГУТ БЫТЬ ПРЕДСТАВЛЕНЫ:
+ ОБВИНЯЕМЫМ;
+ ПОДОЗРЕВАЕМЫМ;
+ СВИДЕТЕЛЕМ;
+ ПОТЕРПЕВШИМ;
#КАКИЕ ВОПРОСЫ ИЗ ПОСТАНОВЛЕНИЯ ОСТАВЛЯЮТ БЕЗ ОТВЕТА ПРИ ФОРМУЛИРОВКЕ ЭКСПЕРТНЫХ ВЫВОДОВ?
- ВОПРОС О ДАННОСТИ НАСТУПЛЕНИЯ СМЕРТИ;
- КАСАЮЩИЕСЯ ХАРАКТЕРА И МЕХАНИЗМА ПРИЧИНЕНИЯ ПОВРЕЖДЕНИЙ;
+ ВЫХОДЯЩИЕ ЗА ПРЕДЕЛЫ СПЕЦИАЛЬНЫХ ПОЗНАНИЙ ЭКСПЕРТА;
- ВОПРОС О ПОСЛЕДОВАТЕЛЬНОСТИ ОБРАЗОВАНИЯ ПОВРЕЖДЕНИЙ;
- ОТРАЖАЮЩИЕ ФАКТ УПОТРЕБЛЕНИЯ АЛКОГОЛЯ.
#О НЕСОМНЕННОМ НАСТУПЛЕНИИ СМЕРТИ СВИДЕТЕЛЬСТВУЕТ:
- ОТСУТСТВИЕ ЗРАЧКОВОГО РЕФЛЕКСА;
- ОТСУТСТВИЕ ВСЕХ РЕФЛЕКСОВ (АРЕФЛЕКСИЯ);
- ОТСУТСТВИЕ ПУЛЬСА И СЕРДЦЕБИЕНИЯ;
+ МЫШЕЧНОЕ ОКОЧЕНЕНИЕ;
- ОТСУТСТВИЕ ДЫХАНИЯ.
#К РАННИМ ТРУПНЫМ ИЗМЕНЕНИЯМ ОТНОСЯТ:
- ГНИЕНИЕ;
- ТОРФЯНОЕ ДУБЛЕНИЕ;
- ПОЗУ «БОКСЕРА»;
+ ТРУПНЫЕ ПЯТНА;
- ЖИРОВОСК.
#К ПОЗДНИМ ТРУПНЫМ ЯВЛЕНИЯМ ОТНОСЯТ:
+ ТОРФЯНОЕ ДУБЛЕНИЕ;
- ЗАМЕРЗАНИЕ ТРУПА;
- ОЛЕДЕНЕНИЕ ТРУПА;
- ТРУПНЫЕ ПЯТНА;
- ТРУПНОЕ ОКОЧЕНЕНИЕ.
#ТРУПНЫЕ ПЯТНА ОБЫЧНО ПОЯВЛЯЮТСЯ:
- В АГОНАЛЬНЫЙ ПЕРИОД;
- В ПЕРИОД КЛИНИЧЕСКОЙ СМЕРТИ;
+ ЧЕРЕЗ 1 - 3 ЧАСА ПОСЛЕ НАСТУПЛЕНИЯ СМЕРТИ;
- ЧЕРЕЗ 10 - 12 ЧАСОВ ПОСЛЕ НАСТУПЛЕНИЯ СМЕРТИ;
- В ПЕРИОД ТЕРМИНАЛЬНОЙ ПАУЗЫ.
#ОСМОТР ТРУПА НА МЕСТЕ ЕГО ОБНАРУЖЕНИЯ ПРОВОДИТ:
- СЛЕДОВАТЕЛЬ;
- ЭКСПЕРТ-КРИМИНАЛИСТ;
- РАЙОННЫЙ ПРОКУРОР;
+ СУДЕБНО-МЕДИЦИНСКИЙ ЭКСПЕРТ;
- УЧАСТКОВЫЙ ИНСПЕКТОР.
#ОРИЕНТИРОВОЧНЫМИ ПРИЗНАКАМИ СМЕРТИ ЯВЛЯЮТСЯ:
+ ОТСУТСТВИЕ СОЗНАНИЯ;
+ АДИНАМИЯ;
+ ОТСУТСТВИЕ ПУЛЬСА НА КРУПНЫХ АРТЕРИЯХ;
+ ОТСУТСТВИЕ РЕАКЦИИ НА БОЛЕВЫЕ РАЗДРАЖИТЕЛИ;
#ДОСТОВЕРНЫМИ ПРИЗНАКАМИ СМЕРТИ ЯВЛЯЮТСЯ:
- АДИНАМИЯ;
- СНИЖЕНИЕ ТЕМПЕРАТУРЫ ТЕЛА ДО 35 ГРАДУСОВ;
- МИДРИАЗ;
+ ТРУПНЫЕ ПЯТНА;
- ОТСУТСТВИЕ СОЗНАНИЯ.
#СТЕПЕНЬ ВЫРАЖЕННОСТИ МЫШЕЧНОГО ОКОЧЕНЕНИЯ ЗАВИСИТ ОТ:
+ ПРИЧИНЫ СМЕРТИ;
+ СТЕПЕНИ РАЗВИТИЯ МУСКУЛАТУРЫ;
+ ТЕМПЕРАТУРЫ ОКРУЖАЮЩЕЙ СРЕДЫ;
+ ДАВНОСТИ НАСТУПЛЕНИЯ СМЕРТИ;
#В ХОДЕ ОСМОТРА ТРУПА НА МЕСТЕ ОБНАРУЖЕНИЯ ПРИ ОПИСАНИИ РАННИХ ТРУПНЫХ ЯВЛЕНИЙ НЕОБХОДИМО ОБРАТИТЬ ВНИМАНИЕ НА:
+ ТРУПНОЕ ОКОЧЕНЕНИЕ;
+ ЛОКАЛИЗАЦИЮ И ХАРАКТЕР ТРУПНЫХ ПЯТЕН;
+ ТЕМПЕРАТУРУ ТРУПА В ПРЯМОЙ КИШКЕ
#ПРИ ОПИСАНИИ ТРУПА НЕИЗВЕСТНОГО ЛИЦА ОСОБЕННО ТЩАТЕЛЬНО СЛЕДУЕТ ОТМЕТИТЬ:
+ ОСОБЫЕ ПРИМЕТЫ;
- ЦВЕТ ТРУПНЫХ ПЯТЕН;
- СТЕПЕНЬ ВЫРАЖЕННОСТИ ТРУПНОГО ОКОЧЕНЕНИЯ;
- СТЕПЕНЬ ВЫРАЖЕННОСТИ ОХЛАЖДЕНИЯ ТРУПА.
#СУДЕБНО-МЕДИЦИНСКОЙ ЭКСПЕРТИЗЕ ПОДЛЕЖАТ ТРУПЫ ЛИЦ, КРОМЕ:
- УМЕРШИХ В РЕЗУЛЬТАТЕ НАСИЛЬСТВЕННЫХ ДЕЙСТВИЙ;
- УМЕРШИХ СКОРОПОСТИЖНО ДОМА;
- УМЕРШИХ СКОРОПОСТИЖНО НА УЛИЦЕ;
- ДОСТАВЛЕННЫХ В ЛЕЧЕБНОЕ УЧРЕЖДЕНИЕ МЕРТВЫМИ;
+ УМЕРШИХ В ЛЕЧЕБНОМ УЧРЕЖДЕНИИ ОТ УСТАНОВЛЕННОГО ХРОНИЧЕСКОГО ЗАБОЛЕВАНИЯ.
#НАРУЖНОЕ ИССЛЕДОВАНИЕ ТРУПА ВКЛЮЧАЕТ СЛЕДУЮЩИЕ ДЕЙСТВИЯ СУДЕБНО-МЕДИЦИНСКОГО ЭКСПЕРТА, КРОМЕ:
- ОСМОТРА ОДЕЖДЫ;
- ОПИСАНИЯ ТРУПНЫХ ИЗМЕНЕНИЙ;
+ ИЗУЧЕНИЯ МАТЕРИАЛОВ ДЕЛА;
- ИССЛЕДОВАНИЯ И ОПИСАНИЯ ОТДЕЛЬНЫХ ЧАСТЕЙ И ОБЛАСТЕЙ ТРУПА;
- ОПИСАНИЯ ПОВРЕЖДЕНИЙ.
#ВНУТРЕННЕЕ ИССЛЕДОВАНИЕ ТРУПА НАЧИНАЕТСЯ СО ВСКРЫТИЯ:
- ГОЛОВЫ;
- ГРУДИ;
- ЖИВОТА;
- СПИНЫ;
+ ПО УСМОТРЕНИЮ ЭКСПЕРТА.
#О НАПРАВЛЕНИИ ОРГАНОВ И ТКАНЕЙ ТРУПА НА ЛАБОРАТОРНОЕ ИССЛЕДОВАНИЕ ДЕЛАЮТ ЗАПИСЬ:
- В ВВОДНОЙ ЧАСТИ;
- В НАЧАЛЕ НАРУЖНОГО ИССЛЕДОВАНИЯ ЧАСТИ;
- ПОСЛЕ ДИАГНОЗА;
+ ПОСЛЕ ОКОНЧАНИЯ ВНУТРЕННЕГО ИССЛЕДОВАНИЯ;
- ПО УСМОТРЕНИЮ СУДЕБНО-МЕДИЦИНСКОГО ЭКСПЕРТА.
#СУДЕБНО-МЕДИЦИНСКАЯ ЭКСПЕРТИЗА ТРУПА ВКЛЮЧАЕТ В СЕБЯ СЛЕДУЮЩИЕ ДЕЙСТВИЯ ЭКСПЕРТА:
+ ОЗНАКОМЛЕНИЕ С ПОСТАНОВЛЕНИЕМ И ДРУГИМИ ДОКУМЕНТАМИ, ПРЕДСТАВЛЕННЫМИ НА ЭКСПЕРТИЗУ;
+ ОПРЕДЕЛЕНИЕ ОБЪЕМА И ПОСЛЕДОВАТЕЛЬНОСТИ ЭКСПЕРТНЫХ ИССЛЕДОВАНИЙ;
+ ПРОВЕДЕНИЕ НАРУЖНОГО И ВНУТРЕННЕГО ИССЛЕДОВАНИЯ ТРУПА;
+ ИЗЪЯТИЕ, УПАКОВКА И НАПРАВЛЕНИЕ БИОЛОГИЧЕСКОГО МАТЕРИАЛА НА ЛАБОРАТОРНЫЕ ССЛЕДОВАНИЯ;
#ПРИ НАРУЖНОМ ИССЛЕДОВАНИИ ТРУПОВ НЕИЗВЕСТНЫХ ЛИЦ НЕОБХОДИМО:
+ ТЩАТЕЛЬНО ОПИСАТЬ ДЕТАЛИ ОДЕЖДЫ;
+ СОСТАВИТЬ СЛОВЕСНЫЙ ПОРТРЕТ;
+ ИЗЪЯТЬ И СОХРАНИТЬ ИМЕЮЩИЕСЯ ЗУБНЫЕ ПРОТЕЗЫ;
+ ДЕТАЛЬНО ОПИСАТЬ ОСОБЫЕ ПРИМЕТЫ И БРОСКИЕ ПРИЗНАКИ;
#В «МЕДИЦИНСКОМ СВИДЕТЕЛЬСТВЕ О СМЕРТИ» СУДЕБНО-МЕДИЦИНСКИЙ ЭКСПЕРТ ДОЛЖЕН УКАЗАТЬ:
+ ОСНОВНУЮ (ПЕРВОНАЧАЛЬНУЮ) ПРИЧИНУ СМЕРТИ;
+ СМЕРТЕЛЬНОЕ ОСЛОЖНЕНИЕ ОСНОВНОГО ЗАБОЛЕВАНИЯ;
+ НЕПОСРЕДСТВЕННУЮ ПРИЧИНУ СМЕРТИ;
+ СОПУТСТВУЮЩИЕ ЗАБОЛЕВАНИЯ;
#СУДЕБНО-МЕДИЦИНСКУЮ ЭКСПЕРТИЗУ (ИССЛЕДОВАНИЕ) ТРУПА ПРОВОДЯТ В СЛУЧАЯХ:
+ НАСИЛЬСТВЕННОЙ СМЕРТИ;
+ ПОДОЗРЕНИЯ НА НАСИЛЬСТВЕННУЮ СМЕРТЬ;
+ ОБНАРУЖЕНИЯ ТРУПА НЕИЗВЕСТНОГО (НЕУСТАНОВЛЕННОГО) ЛИЦА;
+ СКОРОПОСТИЖНОЙ СМЕРТИ ПРИ ОТСУТСТВИИ ПРЕДШЕСТВУЮЩИХ МЕДИЦИНСКИХ НАБЛЮДЕНИЙ;
#ПРИ СУДЕБНО-МЕДИЦИНСКОЙ ЭКСПЕРТИЗЕ ТРУПА ДОЛЖНЫ БЫТЬ РЕШЕНЫ СЛЕДУЮЩИЕ ВОПРОСЫ:
+ ПРИЧИНА СМЕРТИ;
+ ВРЕМЯ НАСТУПЛЕНИЯ СМЕРТИ;
+ ХАРАКТЕР ТРАВМИРУЮЩЕГО ПРЕДМЕТА, КОТОРЫМ ПРИЧИНЕНЫ ПОВРЕЖДЕНИЯ;
+ МЕХАНИЗМ ПРИЧИНЕНИЯ ПОВРЕЖДЕНИЯ;
#ПРИ СУДЕБНО-МЕДИЦИНСКОМ ИССЛЕДОВАНИИ ТРУПА ОБЯЗАТЕЛЬНО ДОЛЖНЫ БЫТЬ ВСКРЫТЫ ПОЛОСТИ:
+ ЧЕРЕПА;
+ ГРУДИ;
+ ЖИВОТА;
#СОСТАВНЫМИ ЧАСТЯМИ «ЗАКЛЮЧЕНИЯ ЭКСПЕРТА» ЯВЛЯЮТСЯ:
+ ОБСТОЯТЕЛЬСТВА ДЕЛА;
+ НАРУЖНОЕ ИССЛЕДОВАНИЕ;
+ ВНУТРЕННЕЕ ИССЛЕДОВАНИЕ;
+ ВЫВОДЫ;
#УКАЖИТЕ НЕПРАВИЛЬНЫЙ ОТВЕТ. ПРИ НАРУЖНОМ ИССЛЕДОВАНИИ ТРУПА НЕОБХОДИМО:
- ОПРЕДЕЛИТЬ ДЛИНУ ТЕЛА;
- ИССЛЕДОВАТЬ ТРУПНЫЕ ИЗМЕНЕНИЯ;
- ОХАРАКТЕРИЗОВАТЬ ПОВРЕЖДЕНИЯ НА ТРУПЕ;
+ УСТАНОВИТЬ ПРИЧИНУ СМЕРТИ;
- СДЕЛАТЬ ОПИСАНИЕ ОДЕЖДЫ НА ТРУПЕ.
#ДЛЯ ОПРЕДЕЛЕНИЯ ФАКТА УПОТРЕБЛЕНИЯ НЕЗАДОЛГО ДО СМЕРТИ АЛКОГОЛЯ ИЗ ТРУПА СЛЕДУЕТ ИЗЪЯТЬ И НАПРАВИТЬ НА СУДЕБНО-ХИМИЧЕСКОЕ ИССЛЕДОВАНИЕ:
+ КРОВЬ;
- ВОЛОСЫ;
- СПЕРМУ
- ЖЕЛЧЬ;
#ПРИ СУДЕБНО-МЕДИЦИНСКОМ ИССЛЕДОВАНИИ ТРУПОВ НОВОРОЖДЕННЫХ МЛАДЕНЦЕВ ВО ВСЕХ СЛУЧАЯХ НЕОБХОДИМО ОПРЕДЕЛИТЬ:
+ ЯВЛЯЕТСЯ ЛИ МЛАДЕНЕЦ ДОНОШЕННЫМ (ЗРЕЛЫМ)?
+ КАКОВА ПРИЧИНА СМЕРТИ?
+ КАКОВА ПРОДОЛЖИТЕЛЬНОСТЬ ВНУТРИУТРОБНОЙ ЖИЗНИ?
+ ЯВЛЯЕТСЯ ЛИ МЛАДЕНЕЦ ЖИВОРОЖДЕННЫМ?
#НАЛИЧИЕ И СТЕПЕНЬ ВЫРАЖЕННОСТИ ЯДЕР БЕКЛЯРА СВИДЕТЕЛЬСТВУЕТ О:
- НОВОРОЖДЕННОСТИ;
+ ДОНОШЕННОСТИ;
- ЖИЗНЕСПОСОБНОСТИ;
- ЖИВОРОЖДЕННОСТИ;
- ПРОДОЛЖИТЕЛЬНОСТИ ВНЕУТРОБНОЙ ЖИЗНИ.
#ПРИ НАРУЖНОМ ИССЛЕДОВАНИИ ТРУПА МЛАДЕНЦА НЕОБХОДИМО ОПРЕДЕЛИТЬ:
+ ПОЛ ПО НАРУЖНЫМ ПРИЗНАКАМ;
+ РАЗМЕРЫ ГОЛОВКИ;
+ ДЛИНУ ТЕЛА;
+ МАССУ ТРУПА МЛАДЕНЦА;
#ПРИЗНАКАМИ ПРИЖИЗНЕННОСТИ ПОВРЕЖДЕНИЯ ЯВЛЯЮТСЯ:
- НАЛИЧИЕ «ПЕРГАМЕНТНЫХ» ПЯТЕН;
+ КРОВОИЗЛИЯНИЯ В ОКРУЖАЮЩИЕ МЯГКИЕ ТКАНИ;
- ОБРАЗОВАНИЕ ОТЛОМКОВ ПРИ ПЕРЕЛОМЕ КОСТИ;
- ДЕФЕКТ ТКАНИ;
- ОБНАРУЖЕНИЕ ЭТИЛОВОГО СПИРТА В КРОВИ.
#ДЛЯ СЛУЧАЕВ ПАДЕНИЯ С БОЛЬШОЙ ВЫСОТЫ ОБЩИМ ПРИЗНАКОМ ЯВЛЯЕТСЯ:
- НАЛИЧИЕ СЛЕДОВ ВОЛОЧЕНИЯ НА ТЕЛЕ;
- ОБНАРУЖЕНИЕ ЭТИЛОВОГО СПИРТА В КРОВИ;
- ОБНАРУЖЕНИЕ НАРКОТИЧЕСКИХ ВЕЩЕСТВ В ОРГАНАХ;
+ ПРЕОБЛАДАНИЕ ВНУТРЕННИХ ПОВРЕЖДЕНИЙ НАД НАРУЖНЫМИ;
#ПО ОСОБЕННОСТЯМ ССАДИНЫ МОЖНО СУДИТЬ О:
+ ФАКТЕ ВНЕШНЕГО НАСИЛИЯ;
+ О МЕСТЕ ПРИЛОЖЕНИЯ СИЛЫ;
+ О НАПРАВЛЕНИИ ДЕЙСТВИЯ СИЛЫ;
+ О ДАВНОСТИ ПРИЧИНЕНИЯ ПОВРЕЖДЕНИЯ;
#ПРИЗНАКАМИ УШИБЛЕННОЙ РАНЫ ЯВЛЯЮТСЯ:
+ НАЛИЧИЕ ОСАДНЕНИЙ ПО КРАЯМ;
